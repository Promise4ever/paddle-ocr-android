# PaddleOcrApp 开发约定

## 修改完成后安装到手机测试

每次完成本项目的代码或资源修改后，都应尝试将最新 Debug 版本安装到已连接的 Android 手机并进行与本次改动相关的测试。

执行原则：

1. 先通过 `adb devices -l` 检查设备是否已连接并授权。
2. 有可用设备时，执行 `gradlew.bat :app:installDebug` 覆盖安装最新版本。
3. 安装成功后启动应用，并检查本次修改涉及的页面或流程是否能够正常打开、没有崩溃；能通过 ADB 完成的交互应继续验证关键结果。
4. 安装应保留应用数据，不主动卸载应用或清除数据。
5. 没有设备、设备未授权或安装失败时，不反复等待，也不因此撤销已完成的代码；在最终回复中说明未能安装或测试的具体原因。
6. 最终回复应明确说明安装是否成功，以及实际测试了哪些内容。
